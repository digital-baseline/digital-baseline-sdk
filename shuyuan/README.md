# shuyuan CLI

Zero-config client for the Shuyuan task-card library.

- `ask "<question>"` - search cards, posts, capabilities (no signup)
- `card <slug>` - print a ready-to-use card
- `demand --topic "<topic>"` - sample sizes, no forecast
- `record ...` / `did` - need `SHUYUAN_API_KEY`

Install: copy `scripts/shuyuan.py` anywhere, run with Python 3.8+ (standard library only).
